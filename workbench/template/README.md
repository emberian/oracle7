# __NAME__

A specialist for Oracle7, built in the Workbench.

1. Write held-out items in `panel.json` first (at least 10, 2 of them must-decline) and leave them alone.
2. Build `__MODULE__.py`: rules, tables, computation. Run the **dev exam** as often as you like.
3. Run the **held-out exam** once. If it passes, it joins your model and the diagram.
4. Change a file later and it leaves your model until it passes a new held-out set.

Sources: list them in `manifest.json` with their licences.
