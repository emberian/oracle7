    +Connect a sensor

    A specialist is a small program that answers one kind of question and declines the rest. It joins your model only by passing its held-out exam; it can only add answers where the core declined.

    With the journal on, each question you ask and whether it was answered is kept in workbench/local/journal.jsonl on this machine only. Nothing is sent or packaged. Declines are grouped into the specialists your model is missing.

    Ask for a function. The code organ hands over only programs it has run, so it writes what it can prove and declines the rest. It can write and prove: a small working website, palindrome check, factorial, vowel count, word count and word frequencies, HTTP routes, regular-expression extraction, memoised recursion, a bank-account class, matrix multiply, fizzbuzz, fibonacci, reverse a string, JSON round-trip, concurrent work, binary search, tower of hanoi, quicksort, sum a list, prime test, a number-guessing game, tic tac toe. The bench runs any code against tests of your own in a separate Python process with a time limit.
